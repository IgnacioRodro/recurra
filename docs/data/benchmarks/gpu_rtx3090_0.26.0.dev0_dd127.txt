# GPU benchmark after DD-127, recurra 0.26.0.dev0

Machine: compute300, 2 x Intel Xeon Silver 4210R (20 physical cores, 40
logical), NVIDIA RTX 3090 24 GB (driver 580.178.04, CUDA 13.0), PyTorch
2.14.1+cu130, numpy 2.5.5. Measured on 2026-11-26 with tools/benchmark_engine.py,
one GPU (cuda:0), 200 windows per size, 8 GB device budget. Compare with
gpu_rtx3090_0.26.0.dev0.txt, measured before DD-127.

Two runs, as printed:

1. speed (bench_opt): --sizes 1280 2560 5120 10240 --engines torch
   --devices cuda:0 --precisions mixed double --fusion both --no-windowed.
   "fused" is the default on CUDA; "not fused" is the same tree with
   gpu_compile=False, so it shows the symmetric line search alone.
2. stage profile (bench_opt_profile): --sizes 2560 10240 --engines torch
   --devices cuda:0 --precisions mixed --profile --no-windowed.
