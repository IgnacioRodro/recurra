# GPU benchmark, recurra 0.26.0.dev0 (DD-125)

Machine: compute300, 2 x Intel Xeon Silver 4210R (20 physical cores, 40
logical), 2 x NVIDIA RTX 3090 24 GB (driver 580.178.04, CUDA 13.0), PyTorch
2.14.1+cu130, numpy 2.5.5. Measured on 2026-11-26 with tools/benchmark_engine.py,
one GPU (cuda:0), 200 windows per size, 8 GB device budget.

Three runs, as printed:

1. small windows (bench_small): --sizes 128 256 384 512 768 1024
   --engines numpy torch --jobs 20 --precisions mixed double --no-windowed.
   The numpy line at 128 points includes starting the 20 worker processes
   (the tool now starts them before timing).
2. stage profile (bench_profile): --sizes 2560 10240 --engines torch
   --precisions mixed --profile --no-windowed. Planning constants of the
   0.26.0.dev0 tree after DD-126 (24 bytes per cell in mixed).
3. full comparison (bench_gpu): --engines numpy torch --jobs 20
   --precisions double mixed single. Planning constants before they were
   tightened (48, 32 and 36 bytes per cell).
