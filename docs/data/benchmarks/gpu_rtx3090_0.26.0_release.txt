# GPU benchmark of the 0.26.0 release

Machine: compute300, 2 x Intel Xeon Silver 4210R (20 physical cores, 40
logical), 2 x NVIDIA RTX 3090 24 GB (driver 580.178.04, CUDA 13.0), PyTorch
2.14.1+cu130, numpy 2.5.5. Measured on 2026-11-26 with tools/benchmark_engine.py
on the tagged release, 200 windows per size, mixed precision, 8 GB budget.

2. recurra_0.26.0_bench_gpu0 and 3. recurra_0.26.0_bench_gpu1: the same sizes,
   --engines torch --no-windowed, cuda:0 and cuda:1 measuring at the same time.
